02 / INSTALL

설치는 네 단계면 됩니다.

패치 작업은 Windows PC에서,
게임 실행은 ARMSX3·RPCSX에서.

  1. 01

    원본 ISO에 한글패치 적용

    압축을 모두 풀고 ApplyPatch.exe를 실행하세요. 원본 ISO와 저장 위치를 선택한 뒤 ‘한글 ISO 만들기’를 누르세요.

    원본 자동 확인 · 여유 공간 5 GB 이상 필요
  2. 02

    공식 업데이트 설치

    에뮬레이터에 1.02 → 1.03 → 1.04 순서로 설치하세요. 이미 1.04까지 설치했다면 건너뛰세요.

  3. 03

    동봉된 한글 PKG 설치

    02_Korean_v0.5_Requires_1.04.pkg를 마지막으로 설치하세요.

  4. 04

    한글 ISO를 기기로 옮겨 실행

    새로 만들어진 한글 ISO로 게임을 실행하면 됩니다.
